# Questionnaires

This directory contains all reusable assessment questionnaires used by the AI Engine.

## Purpose

Convert patient responses into structured clinical findings.

## Contents

- Intake questionnaires
- TCM Ten Questions (十问)
- Symptom-specific questionnaires
- Follow-up questionnaires
- Adaptive question trees
- Scoring rules
- Question mappings

## Notes

This directory stores knowledge only.

No prompts.
No application code.
No implementation logic.
