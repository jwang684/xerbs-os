# AI Schemas

## Overview

Schemas define every AI input and output.

Schemas are the contract between

Engine

Modules

Providers

Application

---

# Principles

Schemas

- are versioned
- are immutable
- are provider-independent

---

# Validation

Every response must pass schema validation.

Invalid outputs are rejected.

---

# Schema Categories

Assessment

Summary

Diagnosis

Formula

Prescription

Follow-up

---

# Evolution

Schema changes should remain backward compatible whenever possible.

Breaking changes require a new version.
