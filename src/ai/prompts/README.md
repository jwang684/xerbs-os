# Prompt Templates

## Overview

Prompt Templates describe AI behavior.

Prompt Templates never contain medical knowledge.

---

# Responsibilities

Prompt Templates

- define instructions
- define output format
- define reasoning strategy

---

# Never

Prompt Templates never contain

- symptoms
- herbs
- formulas
- syndrome rules
- contraindications

These come from the Knowledge Base.
