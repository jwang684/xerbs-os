# Diagnosis Pattern Catalog — Canonical Names

**Diagnosis Pattern Catalog · Content Sprint · Authoring (v1).** Status:
**PROPOSED — PENDING REVIEW.** This is authored knowledge content for the
`diagnosisPatternCatalog` Vocabulary interface: the identity root of the diagnosis tier,
identity only. It is a representation-neutral list of canonical diagnosis-pattern names; it
is not yet wired to the loader/registry/contract (a later step) and contains no meaning,
definitions, symptoms, mappings, treatment guidance, recommendations, reasoning, aliases,
translations, categories, or metadata.

**Canonical naming convention (editorial standard applied to every entry):** the canonical
pattern name in English Title Case, one canonical representation per identity (short
connecting words such as "and", "the", "in", "with" in lower case). Each entry is exactly
one canonical name and nothing else. One entry per identity; aliases, alternate spellings,
and translations are not separate entries.
